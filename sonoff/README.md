# Sonoff device catalog

Product-specific Sonoff devices for HouseWire.

- Library id: `housewire.sonoff`
- Depends on: `housewire.default`
- Initial version: `0.1.0`

This directory is ready to become the `housewire-catalog-sonoff` repository.

## Installation

Install the catalog and its default catalog dependency from PyPI:

```bash
pip install housewire-catalog-sonoff
```

HouseWire discovers the installed catalog through the `housewire.catalog`
entry-point group using its manifest id, `housewire.sonoff`.
